## Descripcion de la actividad
Conocer y aprender como utilizar Git, Github y versionamiento de archivos (control de versiones) , en base a una practica e investigacion.

  ## Que es Git?
  Git es un sistema de control de versiones que permite registrar y organizar los cambios que se realicen en los archivos de un proyecto. Con Git se puede guardar el estado de un proyecto en diferentes momentos mediante los commits, consultar el historial de cambios y regresar a una version anterior cuando sea necesario.

  # Como se usa Git? 
  Git se utiliza principalmente desde una terminal, como Git Bash, mediante diferentes comandos. Primero se crea o se selecciona una carpeta para el proyecto y se utiliza git add y se guardan los cambios con la rama principal mediante un merge. Git tambien puede conectarse con un repositorio remoto en GitHub para guardar y compartir el proyecto en internet.

  # Que recomendaciones debo de saber antes de usar Git?
  Antes de utilizar Git es importante conocer algunos conceptos basicos con repositorio, commit, rama, mergen y repositorio remoto. Tambien es recomendable guardar los cambios importantes mediante commits y utilizan mensajes claros para saber que se modifico en cada momento. Se debe de revisar el estado del proyecto con git status antes de realizar operaciones y tener cuidado de estar trabajando en la rama correcta. Si se utiliza GitHub, tambien es necesario configurar Git y autentificar la conexion en la cuenta correspondiente.

## GitHub

# Que es HitHub?
GitHub es una plataforma en nube basada en el sistema Git que permite almacenar, compartir y colaborar en codigo de programacion de manera conjunta. Funciona simultaneamente como un repositorio de control de versiones y un portafolio profesional para desarrolladores.

# Como se usa?
Para usar GitHub de forma basica, debes seguir un flujo de trabajo estandar que conecta tu computadora (entorno local) con la nube (entorno remoto).

# Que recomendaciones debo de saber antes de usar GitHub?
Git controla las versiones de codigo en la computadora, mientras que GitHub es una plataforma en la nube para almacenar y compartir proyectos. Es recomendable utilizar un archivo .gitignore desde el inicio para evitar subir informacion confidencial, trabajar en ramas separadas y documentar el repositorio con un archivo README.md.Puedes consultar mas informacion directamente en GitHub.

## El versionamiento de archivos (control de versiones)

# Que es control de versiones?
El control de versiones (o versionamiento de archivos) es un sistema que registra los cambios realizados en un archivo o conjunto de archivos a lo largo del tiempo. Su proposito principal es permitirte recuperar versiones especificas mas adelante, comparar modificaciones y trabajar en equipo sin destruir el trabajo de los demas.

# Como se usa?
Para usar el control de versiones (con Git), sigues un ciclo basico de 4 pasos en tu terminal:git init: Creas el sistema de control en la carpeta de tu proyecto.git add .: Seleccionas los archivos que quieres guardar.git commit -m "mensaje": Tomas la "foto" y guardas la version con una descripcion de lo que cambiaste.git push: Subes esa version a internet (GitHub) para respaldarla.

# Que recomendaciones debo de saber?
Antes de usar cualquier tipo de software, herramienta digital, medicamento o servicio, la recomendacion universal es entender su proposito principal, leer las instrucciones basicas y configurar la seguridad.
